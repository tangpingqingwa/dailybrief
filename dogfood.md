# Founder dogfood — 14 days

Required before calling M2 launched (SPEC §12 #7, BUILD §7). Keep this file in-repo; update via PR after each day.

This checklist is **not done**. Do not treat the existence of this file as a completed 14-day run.

Rule: the founder’s morning brief comes only from DailyBrief. Opening TikTok / Reddit / X “following” by habit is product debt — log it that day.
